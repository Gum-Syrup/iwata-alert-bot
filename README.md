# 岩田望来（JRA）的中重視アラートBot (`iwata-alert-bot`)

2026年の岩田望来騎手（JRA騎手コード `01174`）の全レースデータから抽出した**的中率＆妙味の高い2本柱条件**を自動監視し、**レース当日の朝（08:15 JST）**と**各レース出走1時間前（発走45〜75分前）**に Discord Webhook へ `@everyone` メンション付きで自動通知する GitHub Actions Bot です。

## 3ステップ初期設定（所要時間：2分）

### 1. Discord で Webhook URL を作成
1. 通知を受け取りたい Discord サーバーのチャンネル設定（歯車アイコン）→ **連携サービス** → **ウェブフック** → **新しいウェブフック**
2. **ウェブフックURLをコピー** をクリック

### 2. GitHub Secrets に登録
1. このリポジトリの **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
2. 以下を入力して保存：
   * **Name**: `DISCORD_WEBHOOK_URL`
   * **Secret**: 手順1でコピーした Webhook URL

### 3. 動作テスト（任意）
1. リポジトリの **Actions** タブ → **Morning Alert (岩田望来 朝イチまとめ)** を選択
2. **Run workflow** をクリック（過去の開催日 `date: 20261123` などを入れるとその日の通知をそのまま Discord でテストできます！）

* 通知スケジュールは [`.github/workflows/morning_alert.yml`](./.github/workflows/morning_alert.yml) / [`.github/workflows/prerace_alert.yml`](./.github/workflows/prerace_alert.yml) で変更可能です。

## Gemini（Neon Extra）との連携運用（追加課金ゼロ）

### ① 出走1時間前アラートの `.txt` 添付（すっきり1メッセージ配信）
出走1時間前アラートのメッセージ本体に、対象レース名だけ自動で埋めた**あなたのROI 600%フルプロンプト `.txt`**（例：`prompt_20261123_東京8R.txt`）をそのまま添付して送ります。Discordの画面を散らかさず、必要なときだけ好きなモデル（Neon Extra等）へ添付またはコピペして即リサーチできます。

### ② `gemini.google.com`「時間指定アクション」用プロンプト（朝イチ自動リサーチ）
`gemini.google.com` の **時間指定アクション（Scheduled Actions）** で毎週 土曜・日曜 08:30 に登録しておくプロンプトです（望来の抽出条件は2本柱のまま固定）。
