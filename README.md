# 岩田望来（JRA）的中重視アラートBot (`iwata-alert-bot`)

2026年の岩田望来騎手（JRA騎手コード `01174`）の全レースデータから抽出した**的中率＆妙味の高い2本柱条件**を自動監視し、**レース当日の朝（08:15 JST）**と**各レース出走1時間前（発走45〜75分前）**に Discord Webhook へ `@everyone` メンション付きで自動通知する GitHub Actions Bot です。

---

## 通知条件（2026年JRA全データ準拠）

### 柱①：ダート（全競馬場対象）
* **通知条件**：`良馬場` × `1勝クラス・3勝クラス以外` ×（`乗り替わり（テン乗り／手綱戻り）` **または** `1〜3人気`）
  * 2026年実績：良×1・3勝除外全体で **157戦 勝率27.4% / 連対42.0% / 複勝52.9% / 単回収225.0%**（1〜3人気は **複勝65.1% / 単回収119.9%**）
* **🔥Sランク判定**：
  * `単勝4.9倍以下`（2026年 良×1・3勝除外：**勝率42.0% / 連対59.4% / 複勝69.6% / 単回収124.3%**）
  * または `5人気以下 × 乗り替わり × コアブースト2個以上`（大穴一撃型）
* **🟢 併せて表示するプラスフィルター**：
  * 乗り替わり（手綱戻り／テン乗り）・美浦（関東馬）・関東開催（東京/中山）・同競馬場馬券内実績・前走4角4番手以内・単勝4.9倍以下・3人気・未勝利/2勝/OP・左回り・少頭数（12頭以下）・後半9〜12R・休み明け叩き2戦目・美浦 伊藤圭三厩舎

### 柱②：芝（東京・札幌を完全除外！）
* **通知条件**：`東京・札幌以外の競馬場` × `1〜3人気のみ`
  * 2026年実績：**163戦 勝率29.4% / 連対49.1% / 複勝65.0% / 単回収114.2%**
* **🔥Sランク判定**：**`2番人気`**（2026年 **勝率38.9% / 連対59.3% / 複勝77.8% / 単回収148.9%**）
* **🟢 併せて表示するプラスフィルター**：
  * 2人気（Sランク）・道悪（稍/重/不：連対55.0%・複勝67.5%）・芝1400m〜1600m（1400mは複勝77.8%）・阪神/新潟/中山・重賞/OP/未勝利/2勝・最終12R・1〜2枠（複勝70%）/7〜8枠（勝率37.8%）

## 3ステップ初期設定（所要時間：2分）

### 1. Discord で Webhook URL を作成
1. 通知を受け取りたい Discord サーバーのチャンネル設定（歯車アイコン）→ **連携サービス** → **ウェブフック** → **新しいウェブフック**
2. **ウェブフックURLをコピー** をクリック

### 2. GitHub Secrets に登録
1. このリポジトリの **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
2. 以下を入力して保存：
   * **Name**: `DISCORD_WEBHOOK_URL`
   * **Secret**: 手順1でコピーした Webhook URL

### 3. 動作テスト（任意）
1. リポジトリの **Actions** タブ → **Morning Alert (岩田望来 朝イチまとめ)** を選択
2. **Run workflow** をクリック（過去の開催日 `date: 20261123` などを入れるとその日の通知をそのまま Discord でテストできます！）

## カスタマイズ

* ルールのしきい値やブースト条件は [`rules.py`](./rules.py) の上部定数・判定ロジックから自由に調整できます。
* 通知スケジュールは [`.github/workflows/morning_alert.yml`](./.github/workflows/morning_alert.yml) / [`.github/workflows/prerace_alert.yml`](./.github/workflows/prerace_alert.yml) で変更可能です。
* Python標準ライブラリのみで動作するため、追加パッケージのインストール不要です。

## Gemini（Neon Extra）との連携運用（追加課金ゼロ）

### ① 出走1時間前アラート → 1タップコピペで即リサーチ（自動添付）
出走1時間前アラートが発火すると、直後に **全出走馬の「騎手・斤量・最新オッズ・脚質・近走（距離/馬場/着順/着差/通過順/上がり3F）」を1つのコードブロックにまとめた Gemini 用プロンプト** が Discord に自動送信されます。
スマホでコードブロックを1タップコピーして `gemini.google.com`（またはGeminiアプリ / Antigravity）で **Neon Extra** を選んで貼り付けるだけで、最新データ込みの展開予想・相手馬選定が数秒で完了します。

### ② `gemini.google.com`「時間指定アクション」用プロンプト（朝イチ自動リサーチ）
`gemini.google.com` の **時間指定アクション（Scheduled Actions）** で **毎週 土曜・日曜 08:30** に以下を登録しておくと、朝の全体リサーチも完全自動化できます（祝日開催日は手動で1回投げるだけでOK）。

```text
今日（日本時間）のJRA中央競馬で、岩田望来騎手が騎乗する全レースをnetkeiba・JRA公式からWeb検索で調べてください（本日JRA開催がない、または騎乗がない場合は「本日該当なし」とだけ返答）。

全騎乗馬のうち、以下の2本柱条件に合致するレースだけを抽出してください：
【柱① ダート（全場OK）】
・ダート × 良馬場予想 × 1勝クラス・3勝クラス以外 ×（前走別騎手からの乗り替わり、または上位1〜3人気）
・注目ブースト：美浦（関東馬）／関東開催（東京・中山）／同競馬場実績／前走4角4番手以内／単勝4.9倍以下／未勝利・2勝・OP／左回り／少頭数／後半9〜12R／美浦・伊藤圭三厩舎

【柱② 芝（東京・札幌は完全除外）】
・東京・札幌以外の芝 × 上位1〜3人気のみ（特に2番人気はSランク扱い）
・注目ブースト：2人気／道悪（稍・重・不）／芝1400m〜1600m／阪神・新潟・中山／重賞・OP・未勝利・2勝／最終12R

抽出した各レースについて、発走時刻順に以下を簡潔にまとめてください：
1. レース名・発走時刻・条件・望来騎乗馬（ランク判定＆該当ブースト）
2. 展開予想（逃げ・先行馬の頭数とペース見立て）
3. 望来を軸にした相手馬（○対抗・▲単穴・△連下2〜3頭・☆穴1頭）と選定根拠（近走・脚質・コース適性・調教）
4. おすすめ買い目案（馬連・ワイド・3連複）
```
